# High Blood Pressure and Diabetes: Care Group Flipcharts (Ghana)

Tablet flipcharts for the six lessons of the Ghana hypertension and diabetes Care Group module.

- `index.html`: landing page listing the six lessons
- `lessons/lesson-1.html` to `lesson-6.html`: the flipcharts (self-contained; pictures embedded)
- `img/`: thumbnails for the landing page

Served with GitHub Pages from the `main` branch root. Open the site on a tablet and use **Add to Home screen**.
